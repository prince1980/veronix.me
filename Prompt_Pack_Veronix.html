Step 2: The Core Workflow Prompts

Copy and paste these exact prompts into the Higgsfield panel inside After Effects to instantly automate the most tedious parts of motion design.

Category 1: The Reference Rebuilder

Drag and drop a Pinterest screenshot directly into the Higgsfield UI, then use this prompt:

"Analyze this UI reference image and completely rebuild the layout. Generate the background, buttons, and text as fully editable shape and text layers."
Why this works

Instead of spending 3 hours manually drawing rectangles and matching font weights, the AI reverse-engineers the layout into a fully editable scene ready for immediate animation.

Category 2: Expression Magic

Stop Googling for syntax. Select the layer you want to animate and drop this into the chat:

"Add an inertial bounce expression to this layer's scale property. Make the amplitude 0.05, frequency 2.0, and decay 5.0."
Why this works

Giving Claude exact math variables (amplitude/frequency) removes the guesswork, guaranteeing a perfectly tuned, physically accurate bounce.

Category 3: Timeline Automation

Select multiple layers in your timeline that you want to reveal sequentially, and use this prompt:

"Write an ExtendScript to loop through all selected layers and stagger their in-points sequentially by exactly 3 frames, starting from the current time indicator."
Why this works

Creates the classic "staircase" layer offset instantly. This replaces minutes of dragging individual layers on the timeline by hand.

Category 4: AI Asset Generation

Instead of switching to Midjourney to find background textures, type this directly inside AE:

"Generate a cinematic, dark moody background texture with subtle smoke. Import it directly into the project panel and place it at the absolute bottom of this composition."
Why this works

Eliminates the entire friction loop of switching browser tabs, downloading files, and dragging them into the project. The AI handles the entire generation and import pipeline.

Category 5: Data-Driven Graphics

Paste a list of names or data points from a spreadsheet into the chat, along with this prompt:

"Duplicate this current 'Lower Third' composition for each name in the list below. In each duplicate, swap the main text layer with the corresponding name."
Why this works

The ultimate agency hack. Turns a 2-hour manual data entry task for a corporate video into a 10-second automated AI execution.

Category 6: The Motion Thief

Drag a video reference of a cool animation directly into the Higgsfield UI, and use this prompt:

"Analyze the motion of the main object in this attached video reference. Replicate its position easing curve onto my selected layer by generating the corresponding keyframes."
Why this works

Stop guessing graph editor curves. This forces the AI's vision model to mathematically extract the velocity from a reference and apply it directly to your layer.

Category 7: The Project Cleaner

When you inherit a messy client file with hundreds of unorganized layers, use this prompt:

"Analyze this composition. Color label all Text layers Red, all Shape layers Blue, and all Pre-comps Green to organize my timeline."
Why this works

Organization separates amateurs from pros. This single prompt instantly color-codes a massive timeline so you can actually read your composition.

Category 8: Audio-Reactive Dynamics

Make sure you have an Audio Amplitude layer generated in your comp, select your graphic layer, and use this prompt:

"Link this layer's Opacity to the Audio Amplitude 'Both Channels' slider. Use linear interpolation so when the audio is between 10 and 30, the opacity maps from 0% to 100%."
Why this works

Writing interpolation math (linear expressions) is notoriously frustrating. This prompt forces Claude to write the exact mapping algorithm instantly.

Category 9: Bulk Font Swapping

When a client suddenly decides they hate the font across the entire project, run this prompt:

"Find every Text Layer in this active composition. Change their font family to 'Outfit-Bold' and perfectly center their anchor points."
Why this works

Claude writes an ExtendScript in the background and runs it immediately, changing 50 text layers in 2 seconds without you clicking into a single menu.

Category 10: Seamless Looping

If you have an animated background or element that needs to loop infinitely, select it and use this prompt:

"Write an expression for this layer's Time Remap property that creates a seamless infinite loop between the first and last keyframes."
Why this works

It automatically handles the notoriously annoying 'loopOut' blank frame issue by perfectly writing the expression syntax for you.
